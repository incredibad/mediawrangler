Protect your account with two-factor authentication?

If MediaWrangler will be reachable from the internet, turn on two-factor authentication (TOTP). It holds API keys for all your media apps, so a leaked password alone shouldn't be enough to get in.

On a LAN-only install you can skip this. You can turn it on any time under Settings → Security.
