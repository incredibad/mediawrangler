Accounts

A person who has a user in one app but not another. Switch one on to add it to the dry run below; nothing is created until you confirm (Jellyfin needs a temporary password typed for it). Passwords are never copied from an app, and the ones you type are sent once and not kept. For Silo you can leave the password blank: the person gets a one-time link to set their own. The new user can open the libraries that match the ones the person can open elsewhere, and is asked to change the password at first sign-in. History reaches it through the switch for that app under Writes.
