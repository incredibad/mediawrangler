Libraries

Each library below is one body of content, such as TV or Movies, and lists where every app keeps it. The names come from {% if master %}{{ master.name }}{% else %}the master{% endif %}, the master, when it is first synced; the other apps' libraries are matched to them by folder name. Comparisons only look inside one library. The order here is the order of the library tabs on every page and of the tables on the overview; use Move up and Move down to change it. The Treated as column is the one folder every app's path is turned into so they can be compared: the media share's folder is the reference, and each app's folder is matched to it.
