Writing to the apps

When switched on for a user in an app, whatever Local says is played is marked played in that app, and an unwatch MediaWrangler sees happen is passed on. Changes are queued and sent straight away; nothing waits for approval. Everything is off by default, and every change here saves as you make it.

Changing files

Off by default. When on, you can move orphaned files (files an arr tracks the folder for but has no record of) to a trash folder from a folder's page on Physical. Nothing is deleted outright: files sit in .mediawrangler-trash inside their library folder, can be put back from Trash, and are deleted for good after 30 days. Each move re-checks that the file is a video inside a library folder, is still there, and that the arr still has no record of it, and is recorded in the audit log.

Leave it empty and each file goes to a .mediawrangler-trash folder inside its own library folder. Or give one folder for everything (a full path as MediaWrangler sees it, for example /media/.trash; it must exist, be writable and sit outside every library folder; start the name with a dot so it is never read as a library). Files are sorted there by date and library. On the same disk a move is instant; on another disk the file is copied, checked, then removed.
