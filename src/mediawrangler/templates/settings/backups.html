Backups

A backup is a complete copy of MediaWrangler: Local, the audit log, every setting and match, plus secret.key and a settings file. Nothing in it is locked, so keep it somewhere you trust. It is made while the app runs. A nightly one is made at {{ nightly_at }} and the newest {{ keep }} are kept; ones you make by hand are kept until you delete them. They sit on this machine's disk, so download one now and then to keep a copy somewhere else.

Restore from a file

Upload a backup made by MediaWrangler. It is checked first, and refused if it comes from a newer version. MediaWrangler then restarts with it. The database it replaces is kept in this folder as pre-restore-…db.

Settings file

Just the setup, not the history: connectors and their keys (in plain text), libraries, match decisions, people and their links. It is also inside every backup as settings.json. Importing adds and updates by name and deletes nothing, so it works on a fresh install or an existing one.
